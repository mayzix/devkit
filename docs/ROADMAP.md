# DevKit Roadmap

This document describes the planned evolution of DevKit.

Our goal is to build a lightweight, reliable and accessible toolbox for developers.

## Current Features

- [x] JSON formatting
- [x] Base64 encoding and decoding
- [x] UUID generation
- [x] JWT decoding
- [x] URL encoding and decoding
- [x] SHA-256 hashing
- [x] Light and dark themes
- [x] Automated tests
- [x] GitHub Pages deployment

## Short-Term Priorities

### User Experience
- [ ] Improve mobile responsiveness
- [ ] Add keyboard shortcuts
- [ ] Improve accessibility
- [ ] Add clearer error messages

### Developer Experience
- [ ] Expand automated test coverage
- [ ] Add code quality checks
- [ ] Improve project documentation
- [ ] Document the internal utility API

### New Utilities
- [ ] Add timestamp converter
- [ ] Add text comparison tool
- [ ] Add color converter
- [ ] Add regular expression tester

## Long-Term Goals

- Explore a reusable JavaScript utility library
- Improve browser compatibility
- Welcome external contributors
- Build a sustainable open-source community

## Community Feedback

Feature requests and bug reports are welcome through GitHub Issues.

The roadmap is flexible and may change based on user feedback and project priorities.
