# Changelog

All notable changes to DevKit will be documented here.

The format follows the principles of Keep a Changelog.

## [Unreleased]

### Added
- Project roadmap documentation.
- Automated tests with GitHub Actions.
- Light and dark theme support.
- Theme preference persistence in the browser.
- Documentation for contributors.

### Improved
- Project documentation and setup instructions.
- Developer experience and project maintainability.

## Versioning

DevKit will use Semantic Versioning:

- MAJOR: incompatible changes.
- MINOR: new backward-compatible features.
- PATCH: backward-compatible bug fixes.
